# 🕌 মসজিদ হিসাব (Mosjid Hishab)
### উন্মুক্ত ও স্বচ্ছ আর্থিক ব্যবস্থাপনা ও মুসল্লি তথ্য পোর্টাল

একটি আধুনিক, মোবাইল-বান্ধব ও শতভাগ স্বচ্ছ মসজিদ আর্থিক হিসাব ব্যবস্থাপনা অ্যাপ। মুসল্লিরা মসজিদে ঝুলানো **কিউআর (QR) কোড স্ক্যান** করে যেকোনো সময় তাদের স্মার্টফোনে মসজিদের বর্তমান তহবিল স্থিতি, জুমার কালেকশন এবং সকল আয়-ব্যয়ের পুঙ্খানুপুঙ্খ হিসাব দেখতে পারবেন।

---

## ✨ প্রধান বৈশিষ্ট্যসমূহ (Key Features)

1. **উন্মুক্ত মুসল্লি ড্যাশবোর্ড (Public Transparency Portal)**:
   - **বর্তমান তহবিল স্থিতি (Current Fund Balance)**: মোট আয়, মোট ব্যয় এবং বর্তমানে মসজিদের হাতে/ব্যাংকে কত টাকা অবশিষ্ট আছে।
   - **চলতি মাসের হিসাব**: চলতি মাসের মোট জমা, মোট খরচ ও উদ্বৃত্ত।
   - **সর্বশেষ জুমার কালেকশন**: সর্বশেষ জুমার দান বাক্সে কত টাকা উঠেছে, উপস্থিত মুসল্লি সংখ্যা।

2. **জুমার নামাজ কালেকশন ট্র্যাকার (Friday Jummah Tracker)**:
   - প্রতি শুক্রবারের জুমার দান বাক্স ১, দান বাক্স ২ বা পৃথক বক্স কালেকশন ট্র্যাকিং।
   - সাপ্তাহিক কালেকশনের তুলনামূলক গ্রাফিক্যাল চার্ট।
   - খুতবার বিষয়, উপস্থিতি ও সংগ্রহকারীর নাম রেকর্ড রাখার সুবিধা।

3. **সকল আয় ও ব্যয়ের স্বচ্ছ হিসাব খাতা (Detailed Transactions Ledger)**:
   - ট্যাব ভিত্তিক ফিল্টারিং: **সব হিসাব**, **+ জমা (আয়)**, **- খরচ (ব্যয়)**, **🕌 জুমার কালেকশন**।
   - সার্চ ও ক্যাটাগরি ফিল্টার (ইমাম সাহেবের বেতন, বিদ্যুৎ বিল, এসি মেরামত, দান বাক্স ইত্যাদি)।
   - এক্সেল / সিএসভি (CSV) ফাইল ডাউনলোড এবং সরাসরি প্রিন্ট করার সুবিধা।

4. **ডিজিটাল মানি রিসিট ও ভাউচার (Digital Receipts & Vouchers)**:
   - যেকোনো আয় বা ব্যয়ের জন্য ১-ক্লিকে অফিশিয়াল ক্যাশ রিসিট / ভাউচার দেখা ও প্রিন্ট করার সুবিধা (কমিটি ও ক্যাশিয়ারের স্বাক্ষরযুক্ত)।

5. **প্রিন্ট উপযোগী কিউআর কোড পোস্টার (Printable QR Code Poster)**:
   - মসজিদের নোটিশ বোর্ড বা প্রবেশপথে ঝুলিয়ে দেওয়ার জন্য আকর্ষণীয় A4 সাইজের নোটিশ পোস্টার তৈরি হয়।
   - পোস্টারে থাকে মসজিদের নাম, ঠিকানা, ইসলামিক হেডার এবং সরাসরি ওয়েবসাইট লিঙ্কের বড় কিউআর কোড।
   - মুসল্লিরা শুধু মোবাইলের ক্যামেরা অন করে কিউআর কোডটি স্ক্যান করলেই লাইভ হিসাব দেখতে পারবেন।

6. **অনলাইন দান ও সাদাকা পোর্টাল (Online Donations)**:
   - বিকাশ (Personal ও Merchant), নগদ, রকেট এবং ব্যাংকের হিসাব নম্বর (১-ক্লিক কপি সুবিধা)।

7. **পিন-সুরক্ষিত কমিটি অ্যাডমিন প্যানেল (Committee Mode)**:
   - ৪ ডিজিটের গোপন পিন কোড দিয়ে কমিটি লগইন।
   - **ডিফল্ট পিন:** `7860` (সেটিংস থেকে পরিবর্তনযোগ্য)।
   - নতুন আয় বা ব্যয় যুক্ত করা, সম্পাদনা ও মুছে ফেলা।
   - **শুক্রবার জুমার কুইক এন্ট্রি মোড** (মাত্র ৩০ সেকেন্ডে শুক্রবারের হিসাব এন্ট্রি)।
   - ডেটা ব্যাকআপ ডাউনলোড (JSON) ও রিস্টোর।

## 🚀 গিটহাব ও ভার্সেলে ডিপ্লয় করার সহজ নিয়ম (Deploy to GitHub & Vercel)

### ধাপ ১: আপনার কম্পিউটারে টেস্ট করা (Local Run)
প্রজেক্ট ফোল্ডারে টার্মিনাল ওপেন করে রান করুন:
```bash
npm run dev
```
এরপর ব্রাউজারে `http://localhost:3000` ওপেন করুন।

---

### ধাপ ২: গিটহাবে পুশ করা (Push to GitHub)

১. [GitHub.com](https://github.com)-এ যান এবং আপনার অ্যাকাউন্টে লগইন করে একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `mosjid-hishab`).
২. আপনার টার্মিনালে নিচের কমান্ডগুলো চালান:

```bash
git init
git add .
git commit -m "Initial commit: Mosjid Hishab"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/mosjid-hishab.git
git push -u origin main
```

*(দ্রষ্টব্য: `আপনার-ইউজারনেম` এর জায়গায় আপনার আসল GitHub ইউজারনেম দিন)*

---

### ধাপ ৩: ভার্সেলে ডিপ্লয় করা (Deploy to Vercel for Free)

১. [Vercel.com](https://vercel.com)-এ যান এবং **"Continue with GitHub"** দিয়ে লগইন করুন (ফ্রি টায়ার যথেষ্ট)।
২. **"Add New..."** -> **"Project"**-এ ক্লিক করুন।
৩. আপনার গিটহাব রিপোজিটরি `mosjid-hishab` নির্বাচন করে **"Import"**-এ চাপ দিন।
৪. Framework Preset স্বয়ংক্রিয়ভাবে `Next.js` শনাক্ত হবে। কোনো সেটিং পরিবর্তনের প্রয়োজন নেই।
৫. **"Deploy"** বাটনে ক্লিক করুন!
৬. মাত্র ১-২ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে এবং আপনি একটি লাইভ লিঙ্ক পাবেন (যেমন: `https://mosjid-hishab.vercel.app`)!

---

### ধাপ ৪: মসজিদের জন্য কিউআর কোড পোস্টার তৈরি ও প্রিন্ট

১. আপনার লাইভ ওয়েবসাইটে ঢুকুন (বা লোকালহোস্টে)।
২. ওপরে থাকা **"কিউআর পোস্টার"** বাটনে ক্লিক করুন।
৩. লিঙ্ক বক্সে আপনার নতুন Vercel লিঙ্কটি (যেমন: `https://mosjid-hishab.vercel.app`) বসিয়ে দিন।
৪. **"পোস্টার প্রিন্ট (A4)"** বাটনে ক্লিক করে সাধারণ প্রিন্টারে প্রিন্ট করে নিন অথবা ল্যামিনেটিং করে মসজিদে লাগিয়ে দিন!

## 🔒 অ্যাডমিন ও কমিটি তথ্য

- **অ্যাডমিন লগইন বাটন**: ওয়েবসাইটের ওপরে ডানে বা নিচে **"কমিটি লগইন"** বাটনে ক্লিক করুন।
- **প্রাথমিক পিন কোড (Default PIN)**: `7860`
- **পিন পরিবর্তন**: লগইন করার পর **"সেটিংস"** -> **"অ্যাডমিন পিন কোড"** ফিল্ডে গিয়ে আপনার পছন্দমত ৪-৮ ডিজিটের নতুন পিন দিয়ে সেভ করুন।
- **ব্যাকআপ রাখা**: প্রতি মাসে বা যেকোনো পরিবর্তনের পর **"সেটিংস"** -> **"ব্যাকআপ ও ডেটা"** ট্যাবে গিয়ে **"ব্যাকআপ ফাইল ডাউনলোড করুন"**-এ ক্লিক করে একটি ফাইল সেভ করে রাখুন।
